# Панель роутера g20

Статическая Telegram Mini App для домашнего бота. Страница на GitHub Pages сама к роутеру не ходит: снимок состояния приходит в ссылке, команды уходят обратно через `Telegram.WebApp.sendData`. Открытая вне Telegram страница показывает заглушку и не рисует устройства.

## Секреты

В репозитории нет пароля роутера, токена бота, адреса админки и WAN-адреса. Проверять подпись `initData` на клиенте нельзя: для HMAC нужен токен бота, его здесь быть не должно. Подпись и пользователя проверяет бот, до любой команды.

Жёстко прошитые префиксы `192.168.*` убраны. Полный адрес устройства показывается, только если бот прислал префиксы в снимке. Иначе виден последний октет (`.15`). Ротировать нечего: секретов в истории страницы не было. Если префиксы раньше считались лишними на публичной странице, они больше не закоммичены.

## Что должен присылать бот

Снимок — JSON в query-параметре `s` (base64url). Хеш Telegram затирает своим, поэтому основной канал — `?s=`, не `#`. После открытия панель убирает `s` из адресной строки, но GitHub Pages уже мог записать запрос в access-лог: в снимке имена, MAC и внешний IP.

Мини-приложение нужно открывать **кнопкой клавиатуры** (`KeyboardButton` с `web_app`). `sendData` из меню, inline-кнопки и прямой ссылки клиент не доставляет.

Поля снимка:

| Поле | Смысл |
| --- | --- |
| `ts` | Unix-время снимка, секунды (миллисекунды тоже принимаются) |
| `vpn`, `g`, `a` | VPN, гостевой Wi‑Fi, AdGuard: `0`/`1` |
| `sel` | Выбранный сервер или `AUTO` |
| `auto` | Тег узла, который сейчас выбран авторежимом |
| `up`, `m`, `ld` | Аптайм, память, нагрузка — короткие строки |
| `w`, `e` | Внешний IP и подпись справа (например DHCP) |
| `n` | Узлы: `[тег, код страны, пинг мс]` |
| `c` | Устройства: `[имя, последний октет, сеть, MAC, флаги, сигнал]` |
| `hg` | Сколько устройств умного дома не влезло в ссылку |
| `co` | Сколько не в сети и скрыто |
| `sub` | Необязательно, но без него видны только окончания адресов. Раньше страница сама подставляла `m` → `192.168.1.`, `g` → `192.168.2.`, `h` → `192.168.3.`. Теперь это должен присылать бот: `{ "m": "192.168.1.", "g": "192.168.2.", "h": "192.168.3." }` |

Сеть устройства: `m` основная, `g` гостевая, `h` умный дом. Старые записи `l2`/`l5` попадают в основную сеть. Флаги: бит 0 — в сети, бит 1 — без интернета. Сигнал `0` или пусто — «по кабелю». MAC — 12 hex-символов, можно с двоеточиями.

Команды, которые панель отдаёт боту (и только их):

- `{ "a": "vpn", "v": 0|1 }`
- `{ "a": "guest", "v": 0|1 }`
- `{ "a": "sel", "t": "AUTO" | тег }`
- `{ "a": "ren", "m": "aabbccddeeff", "n": "имя" }` — имя 1–24 символа
- `{ "a": "blk", "m": "aabbccddeeff", "v": 0|1 }`
- `{ "a": "speed" }`, `{ "a": "report" }`, `{ "a": "refresh" }`, `{ "a": "reboot" }`

Бот обязан заново проверить `initData` (подпись, `auth_date`, свой user id) и отбросить команду, если панель открыта не владельцем. Клиентская проверка только отсекает обычный браузер.

## Сборка

`index.html` и `p.html` — одна и та же собранная страница (`p.html` оставлен, если бот открывает его напрямую). Исходники: `shell.html`, `panel.src.js`, `logic.mjs`, `tg.js`.

```sh
./build.sh
node --test test/logic.test.mjs
```

`tg.js` — официальный `telegram-web-app.js` с [telegram.org/js/telegram-web-app.js](https://telegram.org/js/telegram-web-app.js), подключён локально, чтобы панель открывалась без чужого CDN. Метод `Serverless` в этом файле — часть SDK; панель его не вызывает.
